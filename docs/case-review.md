# 同一件事的 AI 关联复盘

复盘现在围绕“同一件现实中的事”组织。用户可以从记录详情点击“AI 查找关联并复盘”，AI 只从最多 40 条历史问题中挑选明确相关的记录，返回记录 ID 和关联理由；相似措辞不足以建立关联。用户也可以手动关联记录，或点击“再次占问这件事”进入起卦页。再次占问会保留原问题作为上下文，并允许补充这段时间的现实进展；完成后，新记录保存一条 followup 关联。

关联是可编辑的。AI 关联、手动关联和再次占问关联均保存为记录 ID、类型、理由、时间与撤销标记。多设备合并按关联时间保留较新的状态；关联记录通过图遍历组成同一件事的记录组。关联不改变卦象、不把两个问题强行合并，也不把预测准确当作关联依据。

当一组记录至少有两次占问时，用户可以点击“AI 对照历次占问”。发送给 AI 的内容包括问题、日期、本卦→变卦、动爻位置、首次与最近解读摘录、现实进展和札记。AI 输出整体脉络、延续判断、变化、无法判断之处和下一阶段观察重点，并且必须把问题变化、解读变化和现实事实变化分开说明。复盘结果按资料签名保存；新占问或进展出现后会提示重新生成，旧结果仍保留。

这项功能不会自动轮询，也不会因为时间到了就替用户起卦。它需要用户主动再次占问或主动触发复盘；这样可以保留“为什么在此时重新问”的上下文，降低事后附会。
