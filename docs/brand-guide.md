# 观象品牌与素材

定位：周易研读与个人复盘工具。

主标语：**看见变化，想清下一步。**

产品说明：用《周易》整理问题，用连续记录看见变化。

## 视觉与表达

| 用途 | 颜色 |
| --- | --- |
| 纸色底面 | `#F4F0E6` |
| 墨色文字 | `#2E302C` |
| 朱砂主操作 | `#B55238` |
| 灰色辅助文字 | `#7D786C` |

沿用太极、细圆环和克制的分隔线。标题使用衬线字体，正文使用系统无衬线字体。手机不依赖外部中文字库才能显示文字。文案优先说明下一步要做什么，保留原版封面与开场动画。

## 素材位置

- `app-icon.svg` 与各尺寸 PNG：站点图标、主屏幕图标；
- `brand-share.svg` / `brand-share.png`：可编辑品牌横图与网页分享预览；
- `promo/`：四张 1080 × 1440 宣传图片，分别保留 SVG 源文件与 PNG；
- `launch-kit.html`：下载入口、首发文案、简介及 40 秒录屏脚本。

启动本地网站后打开 `/launch-kit.html` 查看素材。公开示例均为虚构演示，不是用户案例或效果承诺；素材的存在不表示已向社交平台发布。

## 分享规则

卡片在本机生成。私人问题与已保存札记每次打开默认不选，用户选择后才加入图片；公开链接仅打开卦文。账号资料、记录 ID、完整 AI 内容和关联记录不进入公开链接。关闭弹窗清理临时图片；生成失败时不提供旧图片下载。
