# 观象网站封面页设计

## 目标

访问 `index.html` 时，每次首先显示独立的品牌封面页。用户点击唯一的“进入观象”按钮后，封面退场，进入现有的“研读总览”。现有研读系统继续作为站内次级界面，导航、数据加载、占筮、典籍阅读和本地记录行为均不改变。

## 方案

采用同页封面层。封面与现有 `.app-shell` 位于同一份 HTML 中，初始时封面可见且研读系统不可交互。点击入口按钮后，由前端添加明确的进入状态类，完成一次短暂过渡，再隐藏封面并恢复研读系统。

不使用单独页面、客户端路由或持久化的“已进入”标记。每次页面重新加载都从封面开始；同一次页面会话中进入系统后，站内视图切换不会再次出现封面。

## 视觉设计

封面采用“天地未判”的当代东方视觉，不复用现有首页的卡片结构。

- 色彩：墨黑 `#171816`、夜青 `#26332f`、纸白 `#eee9de`、朱砂 `#b55238`、金石灰 `#8f9189`。
- 字体：沿用项目现有中文衬线与无衬线字体栈，避免新增外部字体依赖。品牌名使用大号衬线体，正文和按钮使用无衬线体。
- 构图：品牌“观象”为首屏主信号；中央六条爻线构成抽象卦象，兼作进入时的过渡主体；引文“观乎天文，以察时变”提供语境；页面仅保留一个“进入观象”按钮。
- 动效：首次显示时只编排一次卦爻显现；点击后爻线向两侧展开、封面淡出。动画不承担功能，系统设置减少动态效果时立即切换。

## 结构与状态

新增一个语义明确的封面容器，包含品牌、卦象图形、引文和入口按钮。现有 `.app-shell` 保持原结构，只增加初始不可交互状态。

页面状态只有两种：

1. `cover`：封面可见，研读系统使用 `inert` 与 `aria-hidden` 隔离，键盘焦点停留在入口按钮。
2. `entered`：封面完成退场并从布局和无障碍树中移除，研读系统恢复交互，焦点移至主内容区域。

状态只存于当前文档内存，不写入 `localStorage`、Cookie 或 URL。刷新页面必定回到 `cover`。

## 交互与兼容

- 点击“进入观象”只触发本地界面切换，不导航、不请求网络。
- JavaScript 不可用时，封面按钮通过 `<a href="#view-home">` 提供可理解的降级入口，核心内容仍可访问。
- 手机端封面保持单列居中，卦象尺寸受视口高度和宽度双重限制，按钮文字不得折断。
- 支持键盘激活、清晰焦点样式和 `prefers-reduced-motion`。
- 封面不受现有明暗主题切换影响；进入后沿用当前主题逻辑。

## 文件改动

- `index.html`：新增封面语义结构，为现有应用主容器补充入口状态属性。
- `styles.css`：新增封面布局、卦象视觉、进入过渡及响应式规则。
- `app.js`：新增最小的入口状态初始化和按钮事件，不改变现有视图路由逻辑。

## 验收标准

- 每次直接访问或刷新网站都首先看到封面，而不是研读总览。
- 首屏明确显示“观象”、引文和唯一的“进入观象”按钮。
- 点击按钮后只进入一次现有研读总览，所有站内导航继续正常工作。
- 桌面和手机尺寸下无内容重叠、横向滚动或文字溢出。
- 减少动态效果开启时可无延迟进入，键盘用户能够完成进入操作。
- `npm run validate` 通过，浏览器控制台无新增错误。
