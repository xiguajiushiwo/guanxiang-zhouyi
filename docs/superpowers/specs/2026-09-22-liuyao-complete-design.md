# 经传解读与六爻纳甲双模式设计

## 目标

在现有大衍筮法和《周易》经传阅读功能上，增加一套可复核、可离线使用的六爻纳甲排盘体系。一次起卦同时产生两种互不混淆的结果：

1. **经传解读**：以本卦、之卦、卦辞、爻辞、彖传、象传和现有研读型解读为主。
2. **六爻纳甲**：以纳甲、六亲、六神、世应、用神、月建、日辰、旺衰、生克、冲合刑害和动变关系为主。

本次实现放在新分支 `codex/liuyao-complete`，不修改 `main`，不自动发布线上版本。

## 定位与边界

六爻纳甲是后世传统占筮体系，不冒充《周易》经文原文。界面明确标注“经传解读”和“六爻纳甲”，并在六爻模式首次进入时解释：纳甲、六亲、世应、六神和旺衰属于传统六爻排盘规则。

当前产品继续使用大衍筮法起卦；本次不新增铜钱法、时间起卦或数字起卦。数据模型预留 `castingMethod`，后续增加方法时不破坏记录格式。

六爻模式提供传统排盘资料和可复核关系，不将任何结果表述为确定预测。健康、法律、财务等问题继续显示现有边界提示。

## 起卦时间与历法

起卦准备阶段增加“起卦时间”设置：

- 默认使用用户设备当前日期、时间和 IANA 时区；
- 用户可以在起卦前手动修改日期、时间和时区；
- 起卦完成后，保存最终采用的 ISO 时间、时区、当地显示时间和 `calendarSource`；
- 记录详情显示“按此时间排盘”，避免用户误以为排盘使用查看时刻；
- 时间无效或时区无法解析时，阻止开始六爻排盘并显示可操作错误。

月建、日辰和时辰由成熟的干支历法库计算，不能用简单的公历月份替代：

- 月建按节气月，而不是公历月；
- 日辰使用当地日期对应的干支日；
- 时辰按当地时间和时区换算；
- 跨节气、跨午夜、夏令时和历史日期必须有测试覆盖。

历法库只负责干支、节气和日期换算；纳甲和六爻规则由项目自己的纯函数模块负责，便于审查和替换。

## 核心数据模型

新增 `liuyao-core.mjs`、`sexagenary.mjs` 和 `liuyao-rules.mjs`，所有计算函数无 DOM、网络和存储副作用。

### 排盘输入

```js
{
  lines: [{ value: 6|7|8|9, moving: boolean }, ... six lines from bottom to top],
  castAt: '2026-09-22T10:30:00+08:00',
  timeZone: 'Asia/Shanghai',
  question: '...',
  category: 'general|career|relationship|study|finance|health',
  yongShenOverride: null | '父母' | '兄弟' | '子孙' | '妻财' | '官鬼' | '世爻'
}
```

```js
{
```

## 六爻规则

### 纳甲

使用标准京房纳甲映射：八卦天干、内外卦地支顺序、阴阳顺逆和五行归属全部集中在规则模块中，不散落在 UI。每一爻保留天干、地支、干支字符串和五行，变爻同时生成变卦对应的纳甲信息。

### 宫位、世应

根据六十四卦所属八宫和宫序计算：

- 八宫卦表固定、可审查；
- 世爻位置来自卦宫序；
- 应爻为世爻对冲位置（三位相隔）；
- 乾、坤等特殊卦按照同一套宫表处理，不在 UI 临时修正。

### 六亲与用神

以卦宫五行为基准，按生克关系映射父母、兄弟、子孙、妻财、官鬼。自动用神只提供建议，不替用户做不可逆判断：

- 事业、工作、考试：优先官鬼或父母，并显示候选项；
- 财务、收入、投资：优先妻财；
- 感情关系：根据问题方向提供妻财、官鬼、世应候选；
- 健康：优先世爻和子孙，并保留手动选择；
- 通用问题：默认世爻，并显示全部候选；
- 用户可以在结果页切换用神，排盘基础数据不变。

用神的自动推荐必须标注“建议”，不能显示为唯一正确答案。

### 六神

按日干起青龙，依次顺排六神到初爻至上爻；六神映射表和起法写在规则模块，显示日干依据。六神只作为传统辅助信息，不被本地现代解读引擎伪装成经典原文。

### 月建、日辰与旺衰

每爻根据月建、日辰和自身五行计算可解释的强弱标签：得令、得地、得势、休囚等。输出同时保留计算依据，至少包括：

- 月建对本爻的生、克、同类、泄、耗；
- 日辰对本爻的生、克、同类、冲、合；
- 变爻和动爻对本爻的影响；
- 最终标签和依据数组。

不输出没有规则依据的“吉/凶”结论；强弱展示为“旺、相、休、囚、死”或项目统一的中文标签，并提供术语说明。

### 生克、冲合、刑害

关系计算覆盖：

- 五行生、克、同类、泄、耗；
- 地支六合、六冲、三合、三会；
- 地支刑、害、破；
- 本卦爻、变卦爻、月建和日辰之间的关系；
- 动爻化回头生、化回头克、化退、化进等可由明确规则推导的标签。

每条关系都携带来源、目标、关系类型和说明，UI 可按爻位展开，避免只显示一个不可复核的“吉凶分数”。

### 动爻与变爻

保留现有六爻取值和变爻规则，并在六爻模式中补充：

- 本爻阴阳到变爻阴阳的变化；
- 动爻的原始纳甲与变爻纳甲；
- 动爻与用神、世爻、应爻、月建、日辰的关系；
- 变爻对本爻的生克冲合；
- 六爻皆变、乾坤用九/用六继续由现有 `reading-rules.mjs` 负责经传取法，六爻纳甲单独显示变卦结构。

## 页面与交互

### 起卦准备

在问题确认区域增加紧凑的时间设置：

- “使用当前时间”按钮；
- 可展开的日期、时间、时区编辑器；
- 当用户修改后显示“将按自定义时间排盘”；
- 进入仪式后锁定时间，避免六爻结果在进行中漂移；
- 重新开始时可保留上次设置，也可恢复当前时间。

### 结果页

现有“本次阅读”改成双模式切换：

- **经传解读**：现有本地解读、AI 解读、卦辞、爻辞、十翼关联；
- **六爻纳甲**：排盘摘要、六爻表格、用神选择、关系展开、术语解释和起卦时间。

经传模式默认打开，保持普通用户的阅读路径；用户点击六爻模式后才显示专业排盘，避免首页和普通结果被术语占满。

六爻表格在桌面端显示完整列，在手机端按爻位显示卡片，默认展示核心列（爻位、纳甲、六亲、世应、动静、旺衰），其余关系通过“展开此爻”查看。

### 历史记录

记录卡片显示模式标签和起卦时间。详情页允许在两种模式间切换；旧记录只显示经传模式。用神选择、复盘札记和 AI 解读继续沿用现有记录结构，并与新增 `liuyao` 字段一起导入导出。

## 错误处理与兼容

- 历法库无法加载时，经传模式仍可用，六爻模式明确显示“无法完成干支排盘”，不生成伪造结果；
- 自定义时间无效时阻止开始仪式；
- 旧历史记录保持可读、可导入、可同步；
- 六爻计算失败不清除已经完成的六爻和经传结果；
- AI、账号、云同步失败不影响本地排盘。

## 测试验收

新增单元测试覆盖：

1. 八卦纳甲映射和六十四卦六爻顺序；
2. 八宫、世爻、应爻；
3. 五行与六亲映射；
4. 六神按日干起法；
5. 干支日、节气月、时辰和时区；
6. 跨节气、跨午夜、夏令时和历史时间；
7. 月建、日辰旺衰和冲合刑害；
8. 动爻、变爻及回头生克；
9. 六种问题类型的用神建议与手动覆盖；
10. 旧记录导入、导出、同步和缺失 `liuyao` 字段兼容；
11. 桌面、窄屏六爻结果布局和展开状态；
12. 现有全部单元测试、浏览器测试和内容校验继续通过。

验收标准：同一组爻和同一起卦时间在不同设备上得到相同排盘；修改起卦时间会改变相应干支与旺衰依据但不会改变原始六爻；经传模式和六爻模式可以独立阅读；旧记录不会因升级丢失。
