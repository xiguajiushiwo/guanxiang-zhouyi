# 经传解读与六爻纳甲使用说明

观象在一次大衍筮法完成后提供两种并列的阅读方式。

## 经传解读

“经传解读”保留原有的《周易》研读路径，展示本卦、之卦、卦辞、爻辞、变爻取法、卦象结构和关联经传内容。页面会区分底本原文、后世研读规则和现代提示，避免把解释性内容标成经文。

## 六爻纳甲

“六爻纳甲”属于后世形成的传统占筮体系，并非《周易》经文原文。排盘包括纳甲、六亲、六神、世爻、应爻、用神、月建、日辰、旺衰、生克、冲合、刑害、动爻和变爻关系，并提供互卦、错卦和综卦索引。

旺衰和爻间关系会保留计算依据，供用户逐项展开复核。系统不根据这些资料直接给出确定的吉凶结论。

## 起卦时间

起卦时间默认采用用户设备的当前日期、时间和 IANA 时区。确认问题前，可以手动修改日期、时间或时区，也可以点击“使用当前时间”恢复设备时间。

问题确认后，本次起卦时间会锁定。月建按节气月计算，日辰和时辰按锁定时刻及其时区计算；之后查看历史记录时仍使用原起卦时刻，不会换成查看当天的时间。

## 用神

系统会根据问题类型给出用神候选和默认建议。这个建议不是唯一断法，用户可以在六爻排盘中手动选择父母、兄弟、子孙、妻财、官鬼或世爻。修改用神只改变排盘的关注项，不会改动原始六爻、纳甲或历法数据。

## 历史记录与旧数据

新记录会把完整六爻排盘与经传结果一起保存。登录用户沿用现有账号同步流程，游客记录继续只保存在本机。

升级前已经存在的占卜记录不会丢失，也不会被强行补算。旧记录仍能查看完整经传解读；详情页会提示该记录创建时尚未保存六爻纳甲排盘。导入、导出和账号同步都允许新旧记录共存。

## 语言与设备

新增界面支持简体中文、English 和 فارسی。桌面端以完整表格展示排盘；手机端把每一爻重排为可扫描的区域，并把详细关系放在展开项中，避免横向滚动。

## 当前发布状态

完整六爻体系目前只在 `codex/liuyao-complete` 分支开发和验证，尚未合并到 `main`，也未发布到 Cloudflare Pages。
