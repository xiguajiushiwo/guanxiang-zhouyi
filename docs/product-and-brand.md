# 观象：从可用工具到有人持续使用的产品

建议定位：**用《周易》整理问题，用连续记录看见变化。**

品牌名保留「观象」，对外说明为「周易研读与个人复盘工具」。主标语建议「看见变化，想清下一步。」首页、社交简介、演示视频统一使用。产品最有价值的完整过程是：一个具体问题 → 卦象与有出处的解读 → 现实行动 → 再次占问 → 对照变化。AI 关联复盘是差异点；六十四卦、起卦仪式和多语言是支撑能力。

以下是 2026-10-30 基于当前代码的产品建议；未实现的项目明确列为待办。本文不是已完成事项清单。

## 先为谁做

第一批用户聚焦两个相近人群：愿意读一点《周易》的初学者，以及在职业、学习、项目选择中习惯写记录的人。先用一个高频场景讲透，例如「准备面试 → 面试反馈 → 下一步行动」。不要同时主打婚恋、财富、预测、学术资料库和万能 AI 助理。

产品成功标准可以先定为：用户完成第一次占问后，能说出一条可执行行动；一周内带着实际反馈回来更新同一件事。无需用占问次数刺激用户反复求一个满意结果。

## 正式推广前还缺什么

| 优先级 | 缺口及当前事实 | 建议验收方式 |
| --- | --- | --- |
| 首批邀请前 | 手机导航稳定性。当前正在修复内页刷新、列表/详情、迟到的 AI 响应和重复渲染 | 在 iPhone Safari、Android Chrome/微信浏览器各实测：连续切页、返回、刷新、弱网、锁屏回来；输入和当前页面都不丢 |
| 首批邀请前 | 账号恢复闭环。现有邮箱密码登录没有找回密码流程 | 做邮箱验证与重置密码、邮件送达测试、明确的账号删除入口；不把验证邮件当作营销订阅 |
| 首批邀请前 | 数据与信任。问题、账号和云记录会存储，主动请求 AI 时会发送相关内容 | 补与真实实现一致的隐私说明、数据删除/导出范围、运营主体与反馈渠道；分享默认不带私人问题 |
| 首批邀请前 | AI 容量。生产配置目前每 IP 每小时 5 次、全站每日 50 次；关联与对照也消耗请求 | 先估算每名用户会消耗多少次；增加清晰额度提示、失败重试、费用与错误监控；校园/公司共享 IP 场景实测后再扩量 |
| 首批邀请前 | 一眼看懂价值。现有封面有气质，但功能价值不够直接 | 一句话定位、三个真实界面截图、一段完整示例；先体验再注册，游客记录升级账号路径清晰 |
| 小规模验证期 | 反馈渠道、支持入口和故障可观测性尚不完整 | 建立用户能找到的反馈入口；记录匿名错误类型和加载耗时，不采集问题正文或 AI 内容 |
| 小规模验证期 | 独立域名和稳定传播入口。现在是 pages.dev | 选定域名后统一 canonical/OG、邮件发件域和对外链接；中国大陆用户用真实网络实测，CDN 不等于国内可达保证 |
| 验证留存后 | 商业化与服务承诺 | 先验证持续复盘的需求，再设计 AI 用量/长程对照付费；保留记录查看与导出，不用焦虑话术推动购买 |

## 品牌形象

保留现有纸色 `#F4F0E6`、墨色 `#2E302C`、朱砂 `#B55238`、灰色 `#7D786C`。纸色占大面积，墨色承载内容，朱砂只点出一个主要动作。继续用太极圆形、细圆环和小朱砂点；避免同时堆印章、八卦阵、金色、烟雾和多套图标。

标题用有书卷气的宋体/衬线体，正文用系统无衬线体。不要让手机等待外部中文字库才显示文字。语气沉静、具体，解释「资料显示什么」「我们怎样理解」「下一步如何验证」。对外只表达产品实际提供的能力，不作准确率、命运或医疗金融结果的保证。

本轮提供的素材：站点图标沿用统一太极标记；`brand-share.svg` 为可编辑的 1200×630 横版品牌图，`brand-share.png` 为网页链接预览；`docs/brand-board.html` 为品牌与宣传文案预览。名称尚未做商标/重名检索，选独立域名前应先查。

## 宣发：先用四周验证一个故事

| 阶段 | 内容与动作 | 观察什么 |
| --- | --- | --- |
| 第 1 周：邀请 | 找 10–20 位目标用户，展示一条脱敏的「面试准备—反馈—复盘」完整路径；邀请自愿试用 | 哪一步需要解释、第一次完成率、手机失败原因 |
| 第 2 周：解释 | 小红书/视频号发「怎么把一个问题问清楚」「为什么要记录当时的判断」；每篇对应一个产品动作 | 看完后是否真的开始具体问题，而非只有点赞 |
| 第 3 周：证明 | 录 30–45 秒真实屏幕演示：输入→解读→记录→七天后的同一件事；示例明确标为虚构，真实案例取得授权并脱敏 | 完成第一次记录后，是否有实际进展更新 |
| 第 4 周：留存 | 访谈回访者和流失者，调整引导；整理可复用的复盘案例 | 7 日回访、同一事项第二次更新、愿意推荐的具体原因 |

先选择一个主要内容平台和一个现有用户反馈渠道。建议主阵地小红书，用图文解释问题与复盘；同步复用到视频号。先做自然内容与邀请，不急着投广告或铺所有平台。这个建议不包含自动创建账号、发帖或发消息。

社交简介候选：

> 观象｜周易研读与个人复盘。读经典，问一件事，记录自己的行动，再看变化怎样发生。

首发文案候选：

> 我做了一个叫「观象」的小工具。你可以从一件具体的事开始，读卦象与经典解读，留下当时的判断和行动。过一段时间再回来，AI 会帮助你对照相关记录，看看问题、理解和现实进展分别变了什么。目前正在邀请一小批愿意认真记录的人试用。

三个可连续发布的选题：

1. 「我把‘能不能成功’改成了这个问题」——展示如何写清情境、目标、时间范围。
2. 「七天前的判断，今天还成立吗？」——展示同一事项的前后对照，用虚构面试案例。
3. 「读完一卦以后，真正值得留下的三句话」——当时如何理解、准备做什么、下次看什么。

## 指标与范围

建议只记录经同意、去标识的事件：进入、开始具体提问、完成占问、保存记录、更新进展、打开同一事项复盘。浏览转开始、开始转完成、7 日回访、同步失败率、AI 成功率和平均成本分别看；不能用总访问量代替价值验证。没有真实数据前，不写“多少人受益”或虚构用户评价。

当前适合先做小范围邀请验证。手机自动化测试不能替代真实 iOS、微信内置浏览器和运营商网络测试；账号恢复、服务容量和反馈机制完成后再扩大宣传。
